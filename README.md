# HawkSportz

HawkSportz is an e-commerce website for custom sports merchandise, clothing, and accessories.

## Website

https://www.hawksportz.ca

## Built With

- Next.js
- TypeScript
- Tailwind CSS
- Supabase
- Stripe
- Resend
- Vercel

## Run Locally

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open:

http://localhost:3000

## Deployment

The website is deployed using Vercel.

Production website:

https://www.hawksportz.ca
